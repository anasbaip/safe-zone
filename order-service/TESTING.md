# Checkout integration tests

With Docker running, execute the full suite from `order-service`:

```sh
bash ./mvnw -B verify
```

`CheckoutIntegrationTest` starts its own disposable MongoDB 7 container using
Testcontainers and Spring Boot service connections. Testcontainers selects the
connection settings and cleans up the container after the suite. No manually
started database or `CHECKOUT_TEST_MONGO_URI` variable is needed.

The suite uses real MongoDB repositories and the real Orders HTTP endpoint;
only Product Service responses are controlled. It verifies successful checkout,
idempotent replay, and stock/price changes between review and order creation.

Checkout integration tests are required: an unavailable Docker daemon fails the
suite instead of silently skipping them. GitHub Actions runs them during its
backend `clean verify` step. Jenkins runs them in its Order Service Tests stage
with `clean test`, before packaging and SonarQube analysis. Jenkins uses its
configured `DOCKER_HOST` and Docker TLS environment for Testcontainers.

JaCoCo reports are generated by Maven's `verify` phase. Jenkins preserves the
execution data from `test` and generates the reports during backend packaging.
